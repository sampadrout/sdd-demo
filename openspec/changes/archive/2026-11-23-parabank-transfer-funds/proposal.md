# Proposal: DEMO-1 ParaBank transfer-funds journey

## Why

Demonstrate Spec-Driven Development end-to-end: ticket → OpenSpec requirements → App Actions → Cypress journey against a public app (ParaBank).

## What Changes

- Register (or log in) a customer
- Navigate to Transfer Funds
- Move money between accounts
- Assert Transfer Complete confirmation

## Out of scope

- Bill Pay, Request Loan, Admin DB reset
- Visual / performance SLAs
